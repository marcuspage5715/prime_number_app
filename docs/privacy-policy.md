# Privacy policy — Prime Checker

**Last updated: 14 November 2026**

Prime Checker is an Android app that checks whether a whole number is prime.

## The short version

The app does not collect, store, transmit or share any personal data. There is no
account, no sign-in and no analytics.

## What the app does with your input

Whatever number you type stays in the app's memory while it is on screen. It is
not written to storage, not logged, and not sent anywhere. When you close the app
or clear the field, it is gone.

The app does not have the Android `INTERNET` permission, so it is technically
incapable of sending anything off your device — even if a future version tried
to. It also declares no other permission that would give it access to your
contacts, location, files, camera, microphone or any other data.

## Data collection

| | |
| --- | --- |
| Personal data collected | None |
| Data shared with third parties | None |
| Advertising | None |
| Analytics or crash reporting SDKs | None |
| Cookies or device identifiers | None |
| Data stored on your device | None |
| Backups | Disabled — the app's data is not copied to Google's servers |

## Permissions

The app requests no permissions from you. After installation the Android
package does contain one signature-level permission,
`<application-id>.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION`, which the AndroidX
Core library declares for its own internal broadcast receivers. It is granted
automatically to the app itself, is never shown to you, and gives no access to
your data.

## Children

The app is suitable for all ages and collects no data from anyone, including
children.

## Changes to this policy

If this ever changes — for example if a future version adds a feature that needs
the network — this page will be updated and the app's store listing will say so
before that version is released.
